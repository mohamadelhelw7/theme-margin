# Bundled font licenses

Margin bundles these typefaces in `assets/`. All of them are published on Google Fonts under the SIL Open Font License, Version 1.1. That license allows bundling and redistribution with software, including commercial themes. The fonts may not be sold on their own.

| Files | Typeface | License |
| --- | --- | --- |
| `schibsted-grotesk-*.woff2`, `schibsted-grotesk-italic-*.woff2` | Schibsted Grotesk | SIL OFL 1.1 |
| `libre-caslon-*.woff2`, `libre-caslon-italic-*.woff2` | Libre Caslon Text | SIL OFL 1.1 |
| `vazirmatn-*.woff2` | Vazirmatn | SIL OFL 1.1 |

Each file keeps the copyright notice embedded by its authors. The files are the subsets served by Google Fonts.
